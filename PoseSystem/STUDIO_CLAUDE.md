# Инструкция для Claude в Roblox Studio

Ты подключён к Roblox Studio этой игры. Здесь сказано, что это за игра, как работает каждая её часть и что именно нужно сделать тебе. **Прочитай целиком, потом выполняй шаги по порядку.**

Подробное описание всех механик (что должен видеть игрок) — в `PoseSystem/MECHANICS.md`. Сверяйся с ним при проверке в Шаге 8.

Источник скриптов и документов: GitHub, репозиторий **`dimamikushev2010-hash/-`**, ветка **`claude/roblox-sit-lie-mechanics-4527sh`**, папка **`PoseSystem/`**.

## 0. Суть

Это игра-город в Roblox. В нём:

| Система | Что происходит в игре |
|---|---|
| **Способности игрока** | Сесть, лечь, встать на колени, невидимость, лазеры из глаз, полёт, превращение в куб |
| **Жители (NPC)** | Ходят по домам и улицам, открывают двери, сидят, болтают, дают задания, дружат с игроком, гуляют с собаками, работают продавцами и охранниками |
| **Расписание** | Время суток и дни недели. Жители живут по распорядку: утро дома, днём в кафе и магазинах, вечером на улице, ночью спят |
| **Погода** | Ясно, облачно, дождь, гроза, туман. Меняется сама. В дождь жители раскрывают зонты или прячутся под крышу, машины едут медленнее |
| **Транспорт** | Машины жителей, поток машин, такси, автобус по маршруту, светофоры. Машины не разворачиваются посреди дороги |
| **Полиция** | Участок с дежурным и офицерами. Вызовы, опрос жителей, задержания, камера |
| **Телефон** | У игрока телефон (клавиша **P**): карта, такси, полиция, автобус, сообщения от жителей, погода, задания, работа, магазин, награды, камера, настройки |
| **Жизнь в городе** | 📦 Работа курьером, 🛍 магазин аксессуаров за монеты, 🏆 достижения, 📷 фоторежим (жители позируют), 💾 сохранение прогресса |

**Всю логику уже написал другой Claude — это скрипты.** Скрипты ничего не знают о карте. Им нужны **метки**: невидимые детали с понятными именами и атрибутами в специальных папках. По меткам скрипт понимает, где появляется житель, где стул, где дорога, где стойка дежурного.

**Твоя работа:**
1. установить скрипты (Шаг 1);
2. расставить метки жителей и зоны для расписания (Шаг 2);
3. собрать шаблоны машин (Шаг 3);
4. разметить дороги (Шаг 4);
5. построить и разметить полицейский участок (Шаг 5);
6. подготовить город к погоде (Шаг 6);
7. подобрать звуки (Шаг 7);
7½. включить новые механики (Шаг 7½ — это 3 минуты);
8. проверить всё и отчитаться (Шаг 8).

Для телефона отдельно ничего ставить не нужно: он берёт данные из меток Шагов 2, 4 и 5 (подробно — в Шаге 4, раздел «Телефон»).

**Код скриптов не трогай.** Меняются только ID звуков в `SoundConfig` и, если попросит владелец игры, числа в `...Config`.

### Общие правила для всех меток
- Метка — это **Part**: `Anchored = true`, `CanCollide = false`, `CanQuery = false`, `CanTouch = false`, `Transparency = 0.5`, яркий цвет. В Studio метки видно, в игре скрипты их прячут сами.
- **Передняя грань (Front)** метки — это направление «куда смотреть / куда ехать». Поворачивай метки осознанно.
- Метки ставь **на пол**, нижней гранью к полу, не в воздухе и не под землёй.
- **Атрибуты** добавляются в Properties → Attributes → «+». Тип атрибута (string, number, boolean) важен.
- **Имена папок и деталей** — точно как написано, с той же буквой и регистром.

## Шаг 1. Установить скрипты

1. Открой файл `PoseSystem/AllScripts.lua`. В нём **52 скрипта**, каждый начинается с заголовка:
   ```
   ----------------------------------------------------------------------
   -- 12. ServerScriptService > Script "NPCServer"
   ----------------------------------------------------------------------
   ```
2. Для каждого блока создай объект **указанного типа** (ModuleScript, Script или LocalScript) **в указанном месте**:
   - ReplicatedStorage;
   - ServerScriptService;
   - StarterPlayer > StarterPlayerScripts.
3. Назови объект **точно** как в кавычках.
4. Вставь в `Source` весь код блока до следующего заголовка, без изменений.
5. Если объект с таким именем уже есть — **замени его код** целиком.
6. Лишних старых копий не оставляй: не должно быть двух скриптов с одним именем.

**Скрипт `NPCDemo`** строит демо-городок, только если в `Workspace` ещё нет папки `NPCSystem`. Как только ты создашь свою `NPCSystem`, он ничего строить не будет. Не удаляй его.

Когда владелец скажет «обнови скрипты», повтори этот шаг: метки на карте при этом не трогай.

## Шаг 2. Жители и расписание — `Workspace > NPCSystem`

Подробности — в `PoseSystem/NPC_SETUP.md`.

```
Workspace
└── NPCSystem (Folder)
    ├── Spawns   (Folder) — где появляются жители
    ├── Points   (Folder) — куда они ходят и что там делают
    └── Doors    (Folder) — двери домов, которые жители открывают сами
```

**Зона (`Zone`)** — главное понятие. Это название места: `Дом1`, `Дом2`, `Кафе`, `Магазин`... Улица — всегда `Street`.
- Житель «живёт» в зоне своей точки появления: это его **дом**.
- По расписанию он ходит: дома ↔ на улице ↔ в «других местах» (все зоны, кроме его дома и `Street`).
- Ночью идёт спать в свою зону.

### Spawns — точки появления
- **Что это:** Part 3 × 0.2 × 3 на полу. Передняя грань — куда житель смотрит после появления.
- **Атрибуты:** `Count` (number) — сколько жителей; `Zone` (string).
- **Сколько:** в каждом доме 1 точка с `Count` = 1–2. На улице 2–3 точки с `Count` = 3–4 и `Zone` = `Street`.

### Points — места занятий
- **Что это:** Part 2 × 0.2 × 2 на полу.
- **Атрибуты:** `Activity` (string) и `Zone` (string). Значения `Activity`:

| Activity | Что делает житель | Куда ставить |
|---|---|---|
| `Idle` | Стоит, осматривается | Комнаты, тротуары |
| `Look` | Смотрит вперёд (передняя грань — на окно, витрину, фонтан) | Перед окном, витриной |
| `Sit` | Сидит на полу | Ковёр, газон |
| `Lie` | Лежит (передняя грань — к ногам, к изножью) | Кровать, диван, газон. **В каждом доме минимум одна точка `Lie`: там спят ночью** |
| `Dance` | Танцует | Площадь, комната |
| `Talk` | Ждёт собеседника и болтает | Площадь, кафе |
| `Work` | Рабочее место: один житель стоит тут в рабочие часы. Плюс атрибут `Role` (string), например `Продавец` | За прилавком |
| `Patrol` | Маршрут охранника: 4–6 точек с одинаковым `Route` (string, например `Guard1`), `Order` (number) 1, 2, 3... и `Role` = `Охранник` | Вдоль улицы, по парку |

- **Стулья, диваны, скамейки:** настоящие **Seat** (Anchored), лежат прямо в `Points`, с атрибутом `Zone`. Seat — это само сиденье (подушка). Житель садится спиной к спинке сам. На стул **не** ставь ещё и точку `Sit`. Между соседними Seat — не меньше 2 стадов.
- **Сколько:** в доме 4–8 точек, на улице 10–20.

### Doors — двери домов
- **Что это:** Part или Model (тогда все детали двери внутри), Anchored, в проёме, в закрытом положении. Двери не приваривай к стенам.
- **Атрибуты:** `Hinge` (string): `Left` или `Right` — сторона петель. Необязательный `Locked` (boolean) — запертая дверь.
- **Проёмы:** шириной от 4 и высотой от 6 стадов, без порогов выше 1 стада.

### Расписание: как живут жители

**Время.** Одни игровые сутки — 20 реальных минут (1 игровой час = 50 секунд). Дни идут по неделе Пн–Вс, суббота и воскресенье — выходные. Время и погода видны сверху экрана. Время хранится в атрибутах `Workspace`: `Hour`, `Day`, `WeekDay`, `Weekend`, `Period`.

| Период | Время | Где чаще всего |
|---|---|---|
| Утро | 6:30–9:00 | Дома (окно, завтрак), спешат |
| День | 9:00–13:00 | Кафе, магазины, гости, улица |
| Обед | 13:00–14:00 | Кафе: любят сесть за стол |
| После обеда | 14:00–18:00 | Улица и другие места |
| Вечер | 18:00–21:00 | Улица: болтают, танцуют |
| Ночь | 21:00–6:30 | Спят дома (на точке `Lie`) |

- **Продавцы** (`Work`) работают с 8:30 до 17:30, обед с 13:00 до 14:00. В выходные отдыхают. **Охранники** обходят маршрут каждый день.
- **В выходные** жители меньше сидят дома, больше гуляют, болтают и танцуют.
- Когда начинается период, жители иногда говорят об этом («Время обеда!», «Ура, выходной!»).
- Настройки — в `NPCConfig.Schedule`, `NPCConfig.Weekend`, `NPCConfig.WorkHours`.

**Что для этого сделать тебе:** днём жителям нужно куда-то ходить. Поэтому:
- сделай **отдельные зоны для кафе, магазинов, парка**, например `Кафе`, `Магазин`, `Парк`. В каждой 4–8 точек;
- **кафе:** 4–6 Seat за столами (обед), 1–2 `Talk`, 1 `Work` с `Role` = `Бариста`;
- **магазин:** `Idle` и `Look` у витрин и полок, 1 `Work` с `Role` = `Продавец` за прилавком;
- **парк:** скамейки (Seat), `Sit` на газоне, `Talk`, `Dance`, `Look` на фонтан;
- у каждого кафе и магазина — дверь в `Doors` и **крыша** (в дождь жители прячутся внутри).

### Свои модели жителей (по желанию)
Положи готовые модели в **`ServerStorage > NPCTemplates`**: Model с Humanoid, **R15**, с HumanoidRootPart. Добавь каждой атрибут `Gender` (string): `M` или `F` — тогда имя берётся из `NPCConfig.MaleNames` / `FemaleNames`. Жители будут появляться случайными копиями этих моделей. Полиция и водитель автобуса остаются в форме. Код для этого менять не нужно.

### Ночное освещение
Фонарям, окнам и вывескам добавь `NightLight` (boolean = true) и положи внутрь PointLight или SurfaceLight. Ночью они светятся сами.

## Шаг 3. Шаблоны машин — `ServerStorage > VehicleTemplates`

Подробности — в `PoseSystem/VEHICLE_SETUP.md`, раздел 1.

Каждая машина — **Model** в папке `VehicleTemplates` с атрибутом `VehicleType` (string): `Civilian`, `Taxi`, `Bus` или `Police`. Сделай минимум:
- 2–3 разные гражданские машины;
- 1 такси;
- 1 полицейскую (в ней должно быть **минимум 3 места**: водитель, напарник и задержанный сзади);
- 1 автобус.

Физику и Anchored скрипт настроит сам: просто собери красивую модель из деталей и **правильно назови детали**.

| Имя | Что это | Правила |
|---|---|---|
| `Body` | Кузов | **PrimaryPart** модели. Передняя грань (Front) — вперёд по ходу, верх — вверх |
| `Door_FL`, `Door_FR`, `Door_RL`, `Door_RR` | Двери | Атрибут `Hinge`: `Front` (обычная), `Back`, `Slide` (сдвижная, для автобуса) |
| `Trunk` | Багажник | Петли у переднего края, открывается вверх |
| деталь с атрибутом `PartOf` = `Door_FL` | Стекло или ручка двери | Двигается с этой дверью (так же `PartOf` = `Trunk`) |
| `Wheel...` | Колёса | Цилиндры, ось вбок |
| `Headlight` | Фары | Внутри SpotLight (Face = Front) |
| `Taillight` | Задние фонари | |
| `Indicator_L`, `Indicator_R` | Поворотники | Оранжевые, спереди и сзади |
| `SirenRed`, `SirenBlue` | Мигалки (полиция) | Можно с PointLight внутри |
| `TaxiSign` | Шашечки (такси) | |
| `Seat_Driver` | Место водителя | **Seat**, `Transparency = 1`, где таз водителя, передом вперёд |
| `Seat_1`, `Seat_2`... | Пассажиры | Как водительское. В автобусе 10+ мест |

- **`Paint` = true** (boolean) — детали, которые перекрашиваются у гражданских машин (кузов, крыша, двери).
- **`NightGlow` = true** — светится вместе с фарами (табло автобуса).
- **Размеры для ориентира:** легковая 5 × 4 × 10 стадов, автобус 7 × 7 × 26.
- **Двери автобуса** справа (со стороны тротуара), `Hinge` = `Slide`.

## Шаг 4. Дороги и транспорт — `Workspace > TrafficSystem`

Подробности — в `PoseSystem/VEHICLE_SETUP.md`, раздел 2.

```
Workspace
└── TrafficSystem (Folder)
    ├── Roads          — точки дорог (граф)
    ├── Parking        — парковки
    ├── BusStops       — остановки
    ├── PoliceCalls    — куда ездит полиция (входы в дома)
    ├── PoliceStation  — участок (Шаг 5)
    ├── TrafficLights  — модели светофоров
    └── Places         — места для такси, полиции и карты в телефоне
```

### Roads — как машины понимают дорогу
Дорога для скрипта — это **точки на осевой линии**, соединённые между собой.
- **Где ставить:** Part 1.5 × 0.3 × 1.5 **по центру дороги**. Не на полосе: скрипт сам ведёт машины по правой полосе, на 3 стада правее центра.
- **Где нужны точки:** на каждом **перекрёстке**, на каждом **повороте**, на прямых — через каждые 30–60 стадов.
- **Имена:** у каждой точки **уникальное имя**: `N1`, `N2`...
- **Атрибут `Links`** (string): соседние точки через запятую, например `N2,N7`. Связь двусторонняя: хватит указать её у одной из двух точек.
- **Атрибут `OneWay`** (boolean = true): для одностороннего движения, тогда связи работают только «отсюда туда».
- **Ширина дорог** — от 12 стадов.
- **Проверь:** из любой точки можно доехать до любой другой, и в графе нет «висящих» точек без связей.

**Пример.** Перекрёсток `X1` и четыре дороги из него к точкам `N1`, `N2`, `N3`, `N4`:
- у `X1`: `Links` = `N1,N2,N3,N4`;
- у остальных точек дорог: `Links` — дальше по своей дороге.

### Без разворотов на дороге
Машины **не разворачиваются посреди дороги**: ни на прямой, ни на перекрёстке. Маршрут строится так, чтобы ехать только вперёд и поворачивать. Развернуться можно только в трёх местах:

1. **На кольце.** 4–6 точек по кругу с атрибутом `OneWay` = true. Связь из каждой точки ведёт в следующую **против часовой стрелки, если смотреть сверху** (правостороннее движение). Последняя точка связана с первой. Въезды и выезды — обычные двусторонние связи с точками кольца. Радиус кольца — от 14 стадов, в центре островок (клумба, фонтан).
2. **На разворотной площадке** — точка с атрибутом `Turnaround` (boolean = true). Сделай там широкую площадку, хотя бы 16 × 16, например в конце улицы или у парковки.
3. **В тупике** — точка, у которой ровно одна связь. Сделай в тупике расширение дороги, чтобы машина там поместилась.

**Где их ставить:** на каждом длинном конце улицы — тупик с площадкой или `Turnaround`; в центре города — хотя бы одно кольцо. Тогда от любой точки до любой можно доехать без разворота.

Если без разворота никак не доехать, скрипт пишет в Output: «Без разворота не доехать от … до … — добавь кольцо или точку с Turnaround», и только тогда разрешает разворот. **Таких строк в Output быть не должно** — исправь граф.

### Светофоры
1. **Центр перекрёстка** — обычная точка, например `X1`.
2. **Точки перед перекрёстком.** На каждой въезжающей дороге поставь за 7–10 стадов до центра отдельную точку (в цепочке `... → P1 → X1`). Атрибуты:
   - `Signal` = `X1` (имя группы);
   - `Phase` = `1` для одной оси (например, восток–запад) или `2` для другой (север–юг);
   - `Toward` = `X1`.
3. **Модель светофора** в `TrafficLights`: Model с атрибутами `Group` = `X1` и `Phase`, внутри детали `Red`, `Yellow`, `Green` (Neon). Для каждой фазы — свой светофор, видимый водителям этой оси.

На перекрёстках без светофоров машины пропускают друг друга сами.

### Parking — парковки
- **Что это:** Part 5 × 0.2 × 10 (для автобуса 7 × 0.2 × 26) рядом с дорогой. Передняя грань — куда смотрит машина.
- **Атрибуты:** `Type` (string): `Civilian` / `Taxi` / `Police` / `Bus`. Для `Civilian` ещё `Zone` (string) — зона дома хозяина.
- **Сколько:**
  - `Civilian`: по одной у домов, **плюс 3–5 свободных** у работы, магазинов и кафе, иначе жителям некуда приезжать;
  - `Taxi`: 2 рядом (стоянка);
  - `Police`: 2 у входа в полицейский участок;
  - `Bus`: 1 (конечная).

### BusStops — остановки
- **Что это:** Part на **тротуаре**, где ждут люди. Ставь на той стороне, где автобус едет по правой полосе.
- **Атрибуты:** `Order` (number) — порядок на маршруте 1, 2, 3...; `Node` (string) — имя точки дороги рядом, где встаёт автобус; `StopName` (string) — название (оно видно в телефоне).
- **Сколько:** 2–4 остановки.

### Crosswalks — пешеходные переходы
Жители ходят **по тротуарам** и переходят дорогу **только по переходам**: TrafficServer сам строит вдоль дорог невидимые зоны «проезжая часть» (по точкам `Roads` и `VehicleConfig.RoadWidth` — проверь, что он равен ширине твоих дорог). Перед переходом житель ждёт на тротуаре, пока проедут машины.
- **Где:** Folder `TrafficSystem > Crosswalks`. В нём Part на каждой зебре: лежит на дороге и **накрывает зебру целиком**, от тротуара до тротуара (на 1 стад заходит на тротуары). Ширина вдоль дороги — 4–5 стадов.
- **Сколько:** на каждой ветке перекрёстка, у остановок, у входа в парк, кафе, магазины — там, где люди хотят перейти. Расстояние между переходами на длинной улице — не больше 60–80 стадов.
- **Если папки нет**, переходы с белой зеброй появятся сами на ветках каждого перекрёстка.
- Проверка: меню F2 → «🗺 Метки» → «🚸 Переходы и проезжая часть» и «🧭 Пути жителей».

### PoliceCalls — куда приезжает полиция
- **Что это:** Part на тротуаре **у входной двери** здания (дома, кафе, магазина), снаружи. Передняя грань — к двери.
- **Атрибут:** `Zone` (string) — зона этого здания. Из этой зоны выходит житель к офицерам.
- **Сколько:** 3–5, у разных зданий. У каждого такого здания должна быть дверь в `NPCSystem > Doors`.

### Places — места города
- **Что это:** Part в интересном месте, на тротуаре у дороги.
- **Название:** имя детали или атрибут `PlaceName` (string): «Кафе», «Парк», «Площадь», «Вокзал»...
- **Где используется:** меню такси, заявления в полицию («где случилось»), значки 📍 на карте телефона.
- **Сколько:** 4–8 штук. Если `Places` пустая, скрипт возьмёт центры зон жителей, но с названиями лучше.

### Телефон — что ему нужно
Телефон игрока (клавиша **P** или кнопка 📱 слева внизу) работает сам. Он берёт данные из меток:

| Приложение | Что делает | Откуда берёт данные |
|---|---|---|
| 🗺 Карта | Дороги, игрок со стрелкой, машины (🚌 🚕 🚓 🚗) в реальном времени, остановки 🚏, участок 🏢, места 📍 | `Roads` + `Links`, `BusStops`, `PoliceStation > Desk`, `Places` |
| 🚕 Такси | Выбрать место — свободное такси приезжает к игроку, ждёт 60 с и везёт за `TaxiPrice` монет | `Places`, такси и стоянка `Taxi` |
| 🚔 Полиция 102 | Заявление: что случилось → где. Реально вызывает наряд. Ниже — статусы заявлений | `Places`, `PoliceCalls` |
| 🚌 Автобус | Маршрут: где автобус стоит и куда едет | `BusStops` (`StopName`, `Order`) |
| 💬 Сообщения | Знакомые жители сами пишут игроку, он отвечает — растёт дружба | Жители (`NPCConfig.Phone`) |
| ☀️ Погода | Погода, дождь, облака, туман, совет | Погода (Шаг 6) |
| 📋 Задания | Текущее задание, монеты, друзья | Жители |
| ⚙️ Настройки | Обои, часы на экране, капли дождя, звуки | — |

**Чтобы карта выглядела хорошо:** у всех точек дорог должны быть правильные `Links`, у остановок — `StopName`, у мест — понятные названия.

## Шаг 5. Полицейский участок — `Workspace > TrafficSystem > PoliceStation`

### Как это работает в игре
1. **Жизнь в участке.** Полицейские ждут вызова внутри: ходят по кабинетам от одной точки `Idle_...` к другой, стоят у столов и кофемашины. **Дежурный** всё время стоит за стойкой на точке `Desk`.
2. **Дежурный.** Игрок подходит к стойке и нажимает **E**. Открывается меню с тремя вкладками:
   - **📝 Заявление** — что случилось (кража, шум, подозрительный человек, драка, потерялась собака) → где (места из `Places`). Заявление **реально вызывает наряд**;
   - **❓ Вопросы** — спросить дежурного: «Что нового в городе?», «Кто сидит в камере?» и другие;
   - **📋 Мои заявления** — статус каждого заявления обновляется в реальном времени: «Принято» → «Наряд выезжает» → «Наряд в пути» → «Наряд на месте» → «Задержанный доставлен в участок» → «Закрыто».
   
   То же самое можно сделать из телефона (приложение 🚔).
3. **Вызов как событие.** Офицеры выходят из участка, садятся в машину и едут с сиреной. У здания паркуются, подходят к двери и **встают порознь**. Из здания выходит житель, офицеры его **опрашивают** (диалог в облачках). Иногда (шанс зависит от вида вызова) жителя **задерживают**: на нём наручники, его ведут в машину, везут в участок и **сажают в камеру** (`Cell`). Через 1–1.5 минуты житель выходит и возвращается к своей жизни. Если дома никого нет — «Похоже, никого нет», и наряд уезжает.
4. **Вызовы бывают сами**, без игрока: раз в 1–3 минуты, ночью чаще.

### Как построить здание
Сделай здание участка **с крышей и дверью** (дверь — в `NPCSystem > Doors`). Внутри, от входа вглубь:

```
        [ Камера (Cell) за решёткой ]   [ Кабинет 1 ]   [ Кабинет 2 ]
                     |                       |              |
   ───────────── коридор (ширина от 5 стадов) ─────────────────
                     |
        [ Стойка дежурного (Counter) ]   ← дежурный стоит ЗА ней (Desk)
                     |
              [ Зал для посетителей ]
                     |
                  [ Дверь ] → тротуар → парковки Police (2 шт.)
```

- **Стойка** — длинный стол (Counter) поперёк зала, примерно 8 × 3.5 × 2. Игрок подходит к ней спереди со стороны входа. За стойкой — проход шириной от 4 стадов, чтобы дежурный мог туда дойти.
- **Кабинеты** — 2–3 комнаты со столами, стульями, шкафами; кофемашина в коридоре. Проходы без порогов, шириной от 4 стадов (по ним ходят офицеры).
- **Камера** — комната с решёткой и **открытым проходом** (или дверью без `Locked`): задержанного заводят внутрь. Внутри скамейка.
- Сделай вывеску «ПОЛИЦИЯ» у входа.

### Метки
Folder `PoliceStation` внутри `TrafficSystem`. Метки — Part 2 × 0.2 × 2 на полу внутри здания:

| Имя | Что это | Сколько |
|---|---|---|
| `Desk` | Где стоит **дежурный** — за стойкой. Передняя грань — **к посетителям**, к входу | 1 |
| `Idle_...` (`Idle_Office1`, `Idle_Office2`, `Idle_Coffee`, `Idle_Window`...) | Где офицеры ждут вызова: у столов в кабинетах, у кофемашины, у окна. Передняя грань — куда смотрят (на стол, на кофемашину) | 4–6, в разных комнатах |
| `Cell` | Центр камеры, внутри за решёткой | 1 |

- Рядом со входом — **2 парковки** `Parking` с `Type` = `Police`, а рядом с ними — точка дороги.
- Офицеров по 2 на машину (`VehicleConfig.PoliceOfficersPerCar`), машин — `VehicleConfig.Count.Police`.
- Тексты дежурного, вопросы, виды вызовов и шансы задержания — в `VehicleConfig` (`DutyQuestions`, `PoliceCallTypes`, `CellTime`...).

## Шаг 5½. Оружие, розыск и правосудие — `Workspace > JusticeSystem`

Подробно, как это работает, — `MECHANICS.md`, раздел 13. Оружие и розыск работают сами. Для полного пути «арест → суд → тюрьма» нужны метки (Part 2 × 0.2 × 2 на полу, передняя грань — куда смотреть). Без них этапы проходят в участке.

**В полицейском участке** (`TrafficSystem > PoliceStation`, рядом с Desk, Idle, Cell):

| Имя | Что это |
|---|---|
| `Mugshot` | Где арестованного фотографируют: у стены с ростомером (сделай стену с белыми линиями роста). Передняя грань — от стены, к камере |
| `Fingerprint` | Стол со сканером отпечатков |
| `Interview` | Комната допроса: стол, два стула, лампа. Метка — где сидит/стоит арестованный |
| `Holding` | КПЗ — камера временного содержания (решётка, скамейка). Если нет — используется `Cell` |

**Суд** — здание с залом: `JusticeSystem > Court` (Folder):

| Имя | Что это |
|---|---|
| `Judge` | Где стоит судья — за высоким столом, лицом к залу. Судья появится сам |
| `Dock` | Скамья подсудимых, лицом к судье |
| `CourtDoor` | На тротуаре у входа в суд — сюда подъезжает полицейская машина (рядом нужна точка дороги) |

**Тюрьма** — отдельное здание с забором: `JusticeSystem > Prison` (Folder):

| Имя | Что это |
|---|---|
| `PrisonDoor` | У ворот тюрьмы снаружи — сюда подъезжает машина (рядом точка дороги) |
| `PrisonCell...` (`PrisonCell1`, `PrisonCell2`…) | В камерах, 2–6 штук. Игрок сидит срок здесь и может ходить в пределах 30 стадов (двор, столовая) |
| `PrisonExit` | Где выпускают на свободу — за воротами |

**Суд — места в зале** (необязательно, в ту же папку `JusticeSystem > Court`; без них реплики идут только субтитрами):

| Имя | Что это |
|---|---|
| `Prosecutor` | Где стоит прокурор — у стола обвинения, лицом к судье |
| `Defense` | Где стоит адвокат — у стола защиты, рядом со скамьёй подсудимых |
| `Witness` | Трибуна свидетеля — сбоку от судьи, лицом к залу |
| `Defender` | Куда встаёт друг-защитник (другой игрок) — рядом со столом защиты |

**В участке** (`TrafficSystem > PoliceStation`, необязательно): `Visit` — снаружи у решётки КПЗ (`Holding`), где стоит адвокат, пока с ним говорят. Не внутри КПЗ.

**Места для общественных работ** — `JusticeSystem > Community` (Folder), необязательно: 10–20 Part на тротуарах, во дворах, у остановок (не на дороге, не внутри домов). Там появляются кучи мусора, которые осуждённый убирает. Без папки — места берутся у `Places`, `BusStops`, `PoliceCalls`.

**🤖 Нейросеть для суда (делает владелец, не ты):** суд работает и без неё («живой спор»). Чтобы реплики писала нейросеть Claude:
1. Владелец получает ключ API на console.anthropic.com (платный аккаунт для взрослых 18+).
2. Creator Hub → игра → **Secrets** → новый секрет: имя `anthropic_api_key`, значение — ключ, домен `api.anthropic.com`. Для проверки в Studio — локальный секрет в Game Settings → Security (если владелец хочет).
3. Game Settings → Security → **Allow HTTP Requests** = вкл.
Ключ никуда не вписывай в код и не присылай в отчёте. Проверка — F2 → «📋 Проверки» → v2.4 → «Нейросеть суда».

**Камеры наблюдения** — `JusticeSystem > Cameras` (Folder), необязательно:
- каждая Part — одна камера: размер 1 × 1 × 1, ставь **на стену на высоте 9–11 стадов**, передняя грань — куда смотрит камера (на улицу, вход, кассу);
- атрибуты (по желанию): `CameraName` (string, например «Магазин», «Почта», «Банк») — так она называется в суде; `Range` (number, по умолчанию 60); `Fov` (number, угол обзора, по умолчанию 80; 360 — купольная);
- поставь 8–15 камер: входы в магазины, кафе, почту, перекрёстки, вход в участок;
- **не ставь** камеры в жилых домах изнутри;
- если папки нет — камеры появятся сами у `Places` и `PoliceCalls` (под навесом или на столбе). Если они встали криво — сделай папку и расставь свои.

- Суд и тюрьма должны быть **доступны по дорогам** (точки `Roads` рядом с `CourtDoor` и `PrisonDoor`) — арестованного везут на машине.
- Двери участка, суда и тюрьмы — **без `Locked`**.
- **Возрастной рейтинг.** Оружие и кровь — это рейтинг **17+** в Roblox. Владелец игры заполняет анкету в Creator Hub → игра → **Maturity & Compliance**. Кровь выключается настройкой `WeaponConfig.Blood = false`.
- Свои модели оружия (по желанию): `ServerStorage > WeaponModels > Pistol` / `Rifle` — Tool с деталью `Handle` (передняя грань — к дулу) и Attachment `Muzzle` на конце ствола.

## Шаг 6. Погода

### Как это работает в игре
- Погода: **☀️ Ясно, ☁️ Облачно, 🌧 Дождь, ⛈ Гроза, 🌫 Туман**. Меняется сама каждые 3–6 минут и **плавно** перетекает за 25 секунд (облака, туман, яркость солнца). После ясной погоды сразу грозы не бывает.
- **Дождь:** струи вокруг игрока и брызги на земле, шум. Тучи темнеют, солнце тускнеет. **Под крышей дождя нет** — скрипт проверяет, есть ли что-то над камерой.
- **Гроза:** вспышки молний и гром с задержкой.
- **Туман:** дымка, вдали ничего не видно, шум ветра.
- **Жители в дождь:** у кого есть зонт, раскрывают его (рука поднята). Остальные уходят с улицы под крышу, ускоряют шаг, жалуются. От грома пугаются.
- **Машины** в дождь и туман едут медленнее и включают фары.
- Погода хранится в атрибутах `Workspace`: `Weather`, `WeatherName`, `WeatherIcon`, `Rain`, `Fog`, `Clouds`. Настройки — в `WeatherConfig`.
- Игрок может выключить капли дождя в телефоне (⚙️ Настройки).

### Что сделать тебе
- **Крыши у всех зданий** — настоящие детали с `CanQuery = true` (обычные Part так и сделаны). Иначе внутри домов будет идти дождь.
- **Навесы** у остановок и кафе: там жители прячутся от дождя.
- В `Lighting` можно поставить свои `Atmosphere` и `Sky`, а в `Workspace.Terrain` — `Clouds`. Скрипт возьмёт их значения за основу. Если их нет — создаст сам.
- Не ставь в `Lighting` скрипты или эффекты, которые сами меняют `Brightness` или туман: они будут спорить с погодой.

## Шаг 7. Звуки — `ReplicatedStorage > SoundConfig`

- **только живые, естественные звуки**: настоящий голос человека, настоящая машина. Никакого пиканья, 8-бит, мемов и музыки;

```lua
local ids = {
	Horn = "rbxassetid://5945905639",
	Siren = "rbxassetid://1334940365",
	-- ...все остальные

for name, id in pairs(ids) do
	local s = Instance.new("Sound")
	s.SoundId = id
	s.Parent = workspace
	local t = os.clock()
	repeat task.wait() until s.IsLoaded or os.clock() - t > 6
	print(name, id, "загружен:", s.IsLoaded, "длина:", s.TimeLength)
	s:Destroy()
end
```

- **Подходит** только звук, который загрузился и у которого длина больше 0.
- **Если не нашёл** ничего хорошего — оставь `""`: тишина лучше плохого звука.

| 🛍 Магазин | Телефон → «Магазин»: кепка, цилиндр, корона, очки, нимб, шарик, радужный след, искры, сердечки. Вещи собираются из деталей прямо на персонаже, прячутся при невидимости и в форме куба | Ничего |
| 🏆 Награды | 17 достижений: полёт, невидимость, лазеры, куб, прогулки, такси, автобус, заявления, друзья, задания, доставки, покупки, фото, ночь. Золотое окно с конфетти и монеты | Ничего |
| 📷 Камера | Телефон → «Камера»: фоторежим на весь экран. Фильтры, зум (+/− или колесо), селфи (поворот — правой кнопкой мыши), кнопка 👁 прячет интерфейс на 3 секунды для чистого скриншота. Жители рядом машут, смеются, говорят «Сыр!». Выход — ✕ или **P** | Ничего |
| 💾 Сохранение | Монеты, покупки, достижения сохраняются между заходами | В Studio: **Game Settings → Security → Enable Studio Access to API Services** = вкл (игра должна быть опубликована). Если выключено — всё работает, но без сохранения, в Output будет `[CityLife] Сохранения недоступны` |

Звук затвора — `SoundConfig.Phone.Shutter` (короткий щелчок камеры). Цены, награды и тексты — в `CityConfig`.

## Шаг 8. Проверка и отчёт

**Сначала — меню отладки.** Запусти Play и нажми **F2** (или кнопку 🛠 слева сверху):
- вкладка **✅ Проверка** → «Запустить проверку». Исправь все ❌ и по возможности ⚠️, запусти снова;
- вкладка **🗺 Метки** — включи слои и посмотри, правильно ли стоят метки и куда смотрят их передние грани (линия от метки). Дороги: все точки жёлтые (красная — без связей), стрелки по направлению движения, кольцо против часовой стрелки;
- вкладка **📋 Новое** — пройди проверки по кнопке ▶ и отметь ✓ или 🐞;
- вкладка **🖥 Output** → «Текстом» — так удобно скопировать ошибки в отчёт.
- вкладка **✅ Проверка** → «🧭 Проверить пути»: дождись конца, каждую недоступную точку (📍 — телепорт к ней) передвинь или убери препятствие;
- вкладка **🩺 Диагностика** — посмотри застревания (👁 — кто и где) и ошибки скриптов; «📋 Скопировать для Claude» — готовый текст для отчёта;
- **F3** — свободная камера, чтобы быстро облететь город и проверить метки.

Если владелец игры хочет открывать меню в опубликованной игре не один: впиши UserId нужных людей в `DebugConfig.Admins` (владелец игры видит меню всегда).

### 1. Запусти игру (Play) и проверь по списку

**Жители и расписание**
- [ ] жители появляются лёжа и встают;
- [ ] ходят по точкам, открывают двери, садятся на стулья лицом вперёд, по одному на место;
- [ ] сверху экрана часы, день недели, период и погода;
- [ ] днём жители ходят в кафе и магазины, в обед сидят за столами, ночью спят дома;
- [ ] продавцы стоят за прилавком в рабочие часы.

Чтобы не ждать целые сутки (20 минут), временно поставь `NPCConfig.DayLengthMinutes = 4`, проверь утро, обед и ночь, а потом **верни 20**.

**Погода**
- [ ] временно поставь `WeatherConfig.Start = "Storm"`, запусти: идёт дождь, вспышки молний, гром, жители раскрывают зонты или уходят под крышу;
- [ ] внутри зданий дождя нет;
- [ ] **верни `WeatherConfig.Start = "Clear"`**.

**Транспорт**
- [ ] машины выезжают с парковок и едут по правой полосе;
- [ ] **нигде не разворачиваются посреди дороги**: только на кольце, на `Turnaround` или в тупике;
- [ ] светофор переключается, машины стоят на красный;
- [ ] автобус идёт к первой остановке, открывает двери;
- [ ] у такси можно нажать **E**.

**Участок**
- [ ] дежурный стоит за стойкой лицом к входу;
- [ ] офицеры ходят между точками `Idle_...` по кабинетам и не застревают;
- [ ] у стойки по **E** открывается меню с тремя вкладками;
- [ ] подай заявление: машина выезжает с сиреной, у здания офицеры встают порознь у двери, выходит житель, идёт опрос;
- [ ] подай несколько заявлений «Драка» (там шанс задержания самый большой): житель в наручниках, его везут в участок, он в камере, потом выходит;
- [ ] во вкладке «Мои заявления» статус меняется.

**Телефон**
- [ ] по **P** (или кнопке 📱) выезжает телефон, экран блокировки → нажатие → рабочий стол;
- [ ] 🗺 Карта: видны дороги, ты, машины двигаются;
- [ ] 🚕 Такси: вызов работает, такси приезжает;
- [ ] 🚔 Полиция: заявление отправляется, статус меняется;
- [ ] 🚌 Автобус: видны остановки по порядку;
- [ ] 💬 Сообщения: поговори с жителем несколько раз (станете знакомыми) и подожди 1–2 минуты — придёт сообщение.

**Жизнь в городе**
- [ ] 📦 «Работа» → «Взять заказ»: на «Почте» коробка, по **E** она в руках (руки вперёд), получатель подсвечен, луч ведёт к нему, у получателя — монеты и «Спасибо!»;
- [ ] 🛍 «Магазин»: купи кепку (монеты дают задания и доставки) — она на голове, сидит ровно; «Снять» убирает; при невидимости вещи пропадают;
- [ ] 🏆 полетай 30 секунд — выезжает золотое окно «Первый полёт», в «Наградах» стоит ✓;
- [ ] 📷 «Камера»: фильтры меняют цвет, селфи показывает лицо, жители рядом машут, ✕ возвращает всё как было;
- [ ] выйди и зайди снова (в опубликованной игре) — монеты и вещи на месте.

**Оружие, розыск, правосудие** (быстрее всего — F2 → «📋 Проверки» → v2.2, кнопки ▶)
- [ ] в рюкзаке пистолет и винтовка; в руке оружие смотрит вперёд (если боком — нужна своя модель в `WeaponModels` или поправить `Grip`);
- [ ] выстрел: вспышка, трассер, след на стене; жители рядом в панике;
- [ ] с оружием у жителей: отходят, кто-то звонит (телефон у уха), через 6 с появляются звёзды;
- [ ] 2★ (меню F2 → «Мир»): машина приезжает к месту, офицеры выходят и ищут; когда видят — звёзды мигают;
- [ ] H рядом с офицером — наручники; дальше по очереди: участок, фото, отпечатки, допрос, КПЗ, суд, тюрьма, свобода;
- [ ] полицейская машина доезжает до суда и тюрьмы по дорогам (если нет — проверь точки дорог у `CourtDoor` и `PrisonDoor`).

**Адвокат, суд, камеры** (F2 → «📋 Проверки» → v2.3, кнопки ▶)
- [ ] в КПЗ слева окно дела, справа чат с адвокатом; кнопки тем и свой текст работают;
- [ ] найм адвоката и залог списывают монеты; после залога сразу суд;
- [ ] в суде: субтитры, карточки свидетелей и записей камер, выбор последнего слова, приговор, вопрос об апелляции;
- [ ] «Арест без улик» заканчивается «ОПРАВДАН» у дверей суда;
- [ ] камеры висят ровно (не в воздухе, не в стене); с оружием рядом — «● REC»; выстрел или E ломают камеру;
- [ ] прокурор, адвокат и свидетель стоят на своих местах в зале (если ставил метки).

**Живой суд** (F2 → «📋 Проверки» → v2.4)
- [ ] «Нейросеть суда» — пишет, готова ли она или чего не хватает (без ключа — нормально, суд идёт «🎲 живым спором»);
- [ ] в суде сверху весы, стрелка двигается; кнопка «✋ Протест!» работает;
- [ ] вопрос подсудимому с вариантами ответа появляется и после ответа суд продолжается;
- [ ] пройди суд 2–3 раза — реплики и исходы разные; в отчёте напиши, какие исходы выпали;
- [ ] «Общественные работы»: жилет, луч к мусору, E убирает, таймер; мусор не в стенах и не под землёй.

### 2. Output
Открой **Output** и найди строки с `[NPC]`, `[Traffic]`, `[RigAnimator]`, `[CityLife]`. Каждая такая строка — подсказка, что не так: например, «нет пути от N3 до N7 — проверь Links», «Без разворота не доехать…» или «у шаблона нет Body». **Исправь всё, на что они указывают**, и запусти ещё раз. Красных ошибок скриптов быть не должно.

### 3. Отчёт владельцу игры
- **скрипты:** сколько установлено и были ли ошибки;
- **жители:** зоны и сколько в каждой Spawns и Points (по видам Activity), сколько дверей, какие зоны для дня (кафе, магазины, парк);
- **транспорт:** какие шаблоны машин сделаны;
- **дороги:** список точек дорог с их `Links`, где светофоры, где кольца, развороты и тупики, сколько парковок каждого типа, остановки по порядку, вызовы полиции, места;
- **участок:** где Desk, сколько и где Idle, где Cell, сколько парковок Police;
- **погода:** у каких зданий есть крыши и навесы;
- **жизнь в городе:** где «Почта», включены ли API Services, как выглядят аксессуары (если кривые — какие);
- **звуки:** таблица «ключ — ID — название — длина», и какие звуки не найдены;
- **проверка:** итог вкладки «✅ Проверка» (сколько ✅ / ⚠️ / ❌ и все ❌ текстом), какие пункты списка прошли, какие нет;
- **Output:** что там осталось.

### Свои доработки — только через настройки
При каждом обновлении скриптов код заменяется целиком, поэтому правки внутри кода пропадают. Всё, что раньше делали правкой кода, теперь — настройки:

| Что | Настройка |
|---|---|
| Стартовые монеты нового игрока | `CityConfig.StartCoins` (например, 1000000) |
| «Ширина» жителя | `NPCConfig.AgentRadius` (по умолчанию 1.2) |
| Жители не ходят по дорогам | Уже встроено (зоны и переходы); строгость — `NPCConfig.RoadCost` |
| Стоимость материалов для пути | `NPCConfig.PathCosts`, например `{ Asphalt = 8 }` |
| Сколько жителей | `NPCConfig.MaxNPCs` |
| Пассажиров не видно | `VehicleConfig.HidePassengers = true` |
| Водитель автобуса в форме | `VehicleConfig.BusDriver`, `BusDriverShirt`, `BusDriverPants` |
| Свои модели и имена по полу | `ServerStorage > NPCTemplates` + `Gender`, `NPCConfig.MaleNames` / `FemaleNames` |
| Машины не тормозят из-за встречных | Уже исправлено в коде |

Если нужна доработка, которой нет в таблице, — **не правь код**, а опиши её в отчёте: её добавят настройкой.

**Старые скрипты** (`Phone`, `HUD`, `NpcSystem` и другие, которых нет в списке 43): перенеси их в `ServerStorage > _Hold` и выключи (`Disabled` / `Enabled = false`). Иначе, например, старый `Phone` делает вторую кнопку 📱.

### Нельзя
- менять код скриптов, кроме ID звуков в `SoundConfig`;
- оставлять изменённые для проверки настройки (`Start`, `DayLengthMinutes`) — верни их;
- делать метки Anchored = false или CanCollide = true;
- давать одинаковые имена точкам дорог;
- класть в `Points` что-то кроме меток и Seat;
- ставить `Locked` на двери участка и камеры.
